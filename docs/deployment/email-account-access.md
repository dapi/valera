# Приглашения и пароли — Super Valera 0.43.0

## Приглашение сотрудника

В ЛК откройте «Команда». Владелец или администратор выбирает роль и,
при необходимости, email. С email письмо отправляется автоматически;
без email создаётся ссылка, которую можно передать сотруднику.

Сотрудник подтверждает email по письму. Для нового аккаунта он задаёт имя
и пароль, для существующего — вводит его текущий пароль. Приглашение
однократное, действует 7 дней, его можно отменить в списке команды.
Письменная ссылка подтверждения email действует 30 минут.

Приглашение с email привязано к этому адресу. Его нельзя принять через
другой адрес или через Telegram в обход подтверждения. Старые приглашения
без email по-прежнему можно принять через Telegram. Веб-приглашение
сотрудника не назначает его владельцем аккаунта без владельца.
У существующего участника принятие приглашения сохраняет текущую роль.

## Пароли

- В ЛК доступна «Сменить пароль» для любой роли: текущий пароль, новый
  пароль (от 8 символов), подтверждение. Текущая сессия сохраняется,
  остальные сессии и старые cross-domain токены перестают работать.
- «Забыли пароль?» есть на главной и tenant-формах входа. Ответ на запрос
  одинаков для существующих и неизвестных email.
- Ссылка восстановления действует 15 минут. После изменения пароля
  использовать её повторно нельзя. Сессии старого пароля отзываются.
- Старый сценарий установки первого пароля по одному лишь знанию email
  заменён подтверждением через почту.

Секретные части новых ссылок находятся в URL fragment (`#token=...`),
который браузер не отправляет HTTP-серверу. Страница переносит token
в фильтруемый POST body и удаляет fragment из адресной строки.
Открытие ссылки почтовым сканером не принимает приглашение и не меняет пароль.

## Почтовый транспорт

Настройки deployment и потребляемый Kubernetes Secret принадлежат
`~/code/brandymint/infra`:

- `values/valera.yaml.gotmpl`: SMTP Yandex, TLS/465,
  `Супер Валера <danil@brandymint.ru>`.
- `scripts/sync-valera-mail-secret.py`: читает
  `pass:mail/yandex/danil@brandymint.ru` в память и передаёт его через stdin
  в `valera-production/valera-mail`, ключ `SMTP_PASSWORD`.
- Письма ставятся в очередь ActionMailer / GoodJob. SMTP-ошибки не скрываются.

В application repository секретных значений нет. Тесты используют test mailer;
для проверки доставки в production использовать только свой согласованный адрес.

## Выпуск и проверка

Миграция добавляет необязательный email приглашения и `users.session_version`.
Существующие сессии версии 0 продолжают работать до смены пароля.
Проверять обычный и мобильный интерфейсы, вход через главный домен с
выбором аккаунта, принятие приглашения, отмену, повторное использование,
неверный email/пароль и истечение срока ссылки.

```sh
bin/rails test
bundle exec brakeman --skip-files docs/ --no-pager -q
```

`docs/` исключён из Brakeman как сохранённые примеры сторонних библиотек,
которые не входят в production image. Не исключать из проверки runtime-код.
