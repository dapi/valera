# Состояние проекта — 04.11.2026

Проект находится на стадии работающего пилота. Реализованы multi-tenancy, отдельные Telegram-боты, текстовые консультации, заявки, кабинет, роли команды, takeover менеджером, ссылки/email-приглашения и управление паролем. Фотоанализ удалён из продукта.

## Текущий выпуск

Исправления по ревью проекта от 04.11.2026: Rails security update, устойчивая обработка Telegram updates, защита повторного создания заявки и конкурентной нумерации, повтор уведомлений, ограничения входа, мобильная навигация. Результат выпуска фиксируется в deployment-документации. В 0.45.0 подтверждено получение email во входящих двух собственных адресов и добавлен общий retained-каталог ассетов для rolling update; [доказательства](../deployment/shared-assets-release.md).

## Открытая очередь

1. Измерить p95 и затраты текущей модели на реальных обезличенных сценариях. Cassette-регрессии не заменяют оценку модели.
2. Проверить восстановление из backup и функциональный мониторинг всей цепочки Telegram → gateway → заявка → уведомление.
3. Согласовать коммерческие условия пилота и платной подписки, тексты обработки данных с их владельцами. Реальный пример результата для менеджера публиковать только на синтетических данных.

Нагрузочная пригодность для масштабирования ещё не подтверждена. Исторический [roadmap](ROADMAP.md) сохранён для контекста; его ранние статусы MVP и фотофункций не описывают текущий продукт.
